## kjdraw_architecture_floor_plan (derived PDF)

`architecture-floor-plan.pdf` was rendered from the DXF above by tools/unseen_dxf_to_pdf.py (ezdxf + matplotlib), so the router sees a PDF with a DXF twin as in Stoa's Swiss data. It is a derived file; text is drawn as outlines, so the PDF has no text layer. The DXF itself is marked SYNTHETIC in its title block (a sample drawing generated for the kjdraw project).
